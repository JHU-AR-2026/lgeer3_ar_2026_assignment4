# lgeer3_ar_2026_assignment4

Lukas Geer (lgeer3), AR Assignment 4.

- Q1e is the Kalman filter with the update step filled in. Run `python Q1e.py`, you need numpy and matplotlib.
- Q1f is the same filter but only predicting, no measurement updates. Run `python Q1f.py`.
- Q2 is the roll-a-ball game in Unity 6000.3.21f1. Open the Q2 folder in Unity Hub, open Assets/Scenes/Assignment4.unity, press Play and click Start. Move with WASD or the arrow keys and jump with space. Q2.mp4 is a recording of it.
